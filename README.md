# Conferences

This repository contains the slides of all conference talks I was allowed to give as a speaker to the community :)

## Structure

Slides are sorted into one folder per year:

- [2018](2018/)
- [2019](2019/)
- [2020](2020/)
- [2021](2021/)
- [2022](2022/)
- [2023](2023/)
- [2024](2024/)
- [2025](2025/)
- [2026](2026/)

Each year folder has its own `README.md` listing the talks given that year.

## Naming convention

Files are named:

```
YYYY-MM-DD - Event - Title.pdf
```

- `YYYY-MM-DD`: date of the talk. Where the exact day isn't known, this is shortened to `YYYY-MM` or just `YYYY`.
- `Event`: name of the conference, meetup, or user group.
- `Title`: title of the talk.

A few older files had no year in their original name. Their dates were verified from each PDF's embedded metadata (creation date) and, where possible, the slide content itself, and have been placed accordingly.
